# Advancements Search

A client-side mod that adds a search feature to the advancements window.

The text you enter is searched in titles, descriptions, and icon item display names for all available advancements. Search results are displayed in a grid that fits the window and sorted by relevance - advancements closest to completion appear at the top, while finished ones move to the bottom. Clicking on a search result opens the tab containing the advancement and smoothly highlights it in the advancements tree.
